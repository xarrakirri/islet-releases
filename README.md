# Islet — музыка в чёлке MacBook

Что умеет: в чёлке видно, что играет, с «динамиком» в цвет обложки; наведи — плеер с кнопками;
на экране блокировки — стеклянная плашка, нажми на обложку — она на весь экран.
Работает с Музыкой, Spotify, Яндекс Музыкой и другими плеерами. Нужна macOS 14 или новее.

## Установка (один раз)

1. Скачай: https://github.com/xarrakirri/islet-releases/releases/latest/download/Islet.zip
2. Открой Islet.zip — появится **Islet**. Перетащи его в папку **Программы**.
3. Запусти Islet. macOS скажет, что «не может проверить разработчика» — нажми **Готово** (не «В корзину»).
4. Открой **Системные настройки → Конфиденциальность и безопасность**, пролистай вниз до строки
   «Программа Islet заблокирована» и нажми **Всё равно открыть**, потом введи пароль от мака.
5. Запусти Islet ещё раз → **Открыть**. Откроются настройки, а в строке меню появится значок ♪.

Если шаг 4 не находится — то же самое одной командой в Терминале:

```bash
xattr -dr com.apple.quarantine /Applications/Islet.app
```

## Обновления

Ничего качать заново не нужно. Когда выйдет новая версия, у значка ♪ в строке меню появится **1**,
а в меню — пункт «Обновление +1». Жмёшь — Islet сам скачается, заменится и перезапустится.
Проверить вручную: значок ♪ → «Проверить обновления».
